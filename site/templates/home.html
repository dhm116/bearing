The answers already exist. They're scattered, and they go stale.

Ownership lives in CODEOWNERS files, directory groups, paging schedules and people's heads. Deploy history sits in CI, incidents in another tool, runbooks in a wiki. Portals try to collect all of it by hand, so catalogs drift and engineers stop trusting them.

AI agents now write a large share of the code, and they can't see any of this context either. They need the same answers people do, with the evidence attached.

“What is this, who owns it, what changed, and how do I safely change it?”

Infer first, declare to override
The graph is built from signals that already exist. Metadata files correct it; they're never required to create it.
Show the evidence
Every fact carries its source, confidence and the time it was true. When sources disagree, Bearing shows the dispute instead of picking one.
Integrate, don't replace
Small adapters read the tools you run, Backstage included. Bearing defines the data worth having and leaves the rest alone.
Contracts first
Every component sits behind a published interface with a conformance suite, so any backend that passes can replace the default.
One answer, everywhere
The same graph answers on the command line, in an agent session through MCP, and later in a browser.
